# Homebrew Tap for LNS

Install the latest signed LNS release and its Caddy dependency:

```bash
brew install --cask crown-dev-studios/tap/lns
```

The cask is generated from tagged releases of [crown-dev-studios/lns](https://github.com/crown-dev-studios/lns). Do not edit it by hand.
